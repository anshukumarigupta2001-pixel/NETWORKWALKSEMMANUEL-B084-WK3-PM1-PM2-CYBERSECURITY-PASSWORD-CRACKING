# Module 2: Password Cracking with Networkwalks Tools

Recovering the password of the locked PDF using Networkwalks' browser-based
Hash Calculator and Password Cracker — no installation required.

## What I did
1. Opened the Networkwalks Hash Calculator and uploaded the locked PDF to extract its hash.
2. Copied the extracted `$pdf$...` hash.
3. Opened the Networkwalks Password Cracker and pasted the hash.
4. Ran the dictionary attack until a match was found.
5. Opened the PDF with the cracked password and captured the flag.

## Result
- **Flag captured:** `nw{networkwalks_flag_260821_1}`
