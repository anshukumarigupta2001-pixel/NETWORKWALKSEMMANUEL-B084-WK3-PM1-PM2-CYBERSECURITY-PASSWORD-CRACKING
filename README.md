## Concepts
- Encryption is reversible with the right key; hashing is one-way and used only to verify a guess.
- `pdf2john` format encodes a PDF's password-related data into a single `$pdf$...` hash string.
- A dictionary attack hashes every word in a wordlist and compares it with the target hash.
